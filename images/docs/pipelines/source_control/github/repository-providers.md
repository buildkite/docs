# GitHub repository provider options

Recreate the provider choices shown in [Connect your Buildkite account to GitHub using the GitHub App](/docs/pipelines/source-control/github#connect-your-buildkite-account-to-github-using-the-github-app), following the [shared screenshot guidance](../../../../../styleguides/working-with-docs-site.md#screenshots).

Use an administrator account in a dedicated Buildkite integration test organization with access to **Repository Providers**. Do not select a provider, connect an account, or install an app.

1. Use Chrome for Testing 158 on macOS with a 1000 × 1320 CSS-pixel viewport, 100% zoom, and pixel density two. Use **System** appearance, set browser color-scheme emulation to light, and verify the product renders in light mode. Wait for `document.fonts.ready` and verify the actual rendered heading, labels, and help text use the native system font (`.SF NS` in Chromium).
1. In the organization, select **Settings** > **Repository Providers**. Verify that **Add Provider** offers both **GitHub** and **GitHub (Limited Access)**. The Limited Access description must end with “Works with self-hosted agents only.” If either option is missing, report it and do not capture a substitute.
1. In the browser DOM, replace only the displayed sidebar organization name with **Acme Inc** for the screenshot. Do not rename the organization. Keep the native default organization icon if it is safe to show. Omit the separate **Connected Providers** panel if it lists private account connections; do not imply that the organization has none. Keep every row in **Add Provider** visible, in its original order, with its original labels, logos, links, and descriptions.
1. At scroll y=0, crop the viewport from (0, 46) at 978 × 1045 CSS pixels. Include the active global **Settings** tab, **Acme Inc**, selected **Repository Providers** item under **Integrations**, **Repository Providers** page heading, and complete **Add Provider** list through the final **Git** row. Exclude the global account bar and browser chrome. Move the pointer out of the crop and clear focus styling.
1. Add one unfilled coral outline (`#e65454`, 4 physical pixels thick) around the two complete GitHub rows together. In the 2× cropped PNG, the rectangle's stroke centerline runs from (543, 605) to (1935, 877). If the layout changes, remeasure the two row bounds and keep the stroke just inside their combined perimeter without covering icons, labels, or descriptions. Do not add numbers or separate outlines.
1. Save `repository-providers.png`. Reload to discard the presentation changes. Repeat from fresh navigation with dark color-scheme emulation, verifying the actual dark product theme, and save `repository-providers-dark.png`. Use the same viewport, zoom, scroll, cleanup, crop, and outline. Reload again to verify the real organization name and connected accounts are unchanged.

Accept two 1956 × 2090 PNGs intended to display at up to 978 × 1045 CSS pixels. Check at 800 CSS pixels wide that **Acme Inc**, the navigation path, and both outlined GitHub choices and their full descriptions are legible. The surrounding list remains intact. Exclude connected account details, real organization identity, the pointer, and hover or focus styling.
