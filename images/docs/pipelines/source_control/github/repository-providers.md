# GitHub repository provider options

Recreate the provider choices shown in [Connect your Buildkite account to GitHub using the GitHub App](/docs/pipelines/source-control/github#connect-your-buildkite-account-to-github-using-the-github-app), following the [shared screenshot guidance](../../../../../styleguides/working-with-docs-site.md#screenshots).

Use an administrator account in a dedicated Buildkite integration test organization with access to **Repository Providers**. Do not select a provider, connect an account, or install an app.

1. Use Chrome for Testing 158 on macOS with a 1000 × 1320 CSS-pixel viewport, 100% zoom, and pixel density two. Use **System** appearance, set browser color-scheme emulation to light, and verify the product renders in light mode. Wait for `document.fonts.ready` and verify the actual rendered heading, labels, and help text use the native system font (`.SF NS` in Chromium).
1. In the organization, select **Settings** > **Repository Providers**. Verify that **Add Provider** offers both **GitHub** and **GitHub (Limited Access)**. The Limited Access description must end with “Works with self-hosted agents only.” If either option is missing, report it and do not capture a substitute.
1. For privacy, hide the sidebar's organization name and icon in the DOM without shifting the menu. Omit the separate **Connected Providers** panel if it lists private account connections; do not imply that the organization has none. Keep every row in **Add Provider** visible, in its original order, with its original labels, logos, links, and descriptions.
1. At scroll y=0, crop the viewport from (0, 46) at 978 × 1045 CSS pixels. Include the active global **Settings** tab, selected **Repository Providers** item under **Integrations**, **Repository Providers** page heading, and complete **Add Provider** list through the final **Git** row. Exclude the global account bar and browser chrome. Move the pointer out of the crop and clear focus styling.
1. Save `repository-providers.png`. Reload to discard the privacy cleanup. Repeat from fresh navigation with dark color-scheme emulation, verifying the actual dark product theme, and save `repository-providers-dark.png`. Use the same viewport, zoom, scroll, cleanup, and crop. Reload again to restore the original view.

Accept two 1956 × 2090 PNGs intended to display at up to 978 × 1045 CSS pixels. Check at 800 CSS pixels wide that the navigation path, both GitHub choices, and their full descriptions are legible. The surrounding list remains intact. Exclude connected account details, organization identity, the pointer, and hover or focus styling.
