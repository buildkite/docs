# Buildkite CLI repository-connection command

The `bk repository-connection` command allows you to view organization repository connections and their GitHub API rate limits from the command line.

## Commands

| Command | Description |
| --- | --- |
| `bk repository-connection list` | List repository connections. |
| `bk repository-connection view` | View a repository connection and its GitHub API rate limit. |

## List repository connections

List repository connections.

List the organization's source control repository connections, such as GitHub
apps, Bitbucket Server, and GitLab Self-Managed. Requires organization
administrator access.

The list does not include GitHub API rate limits; use "bk repository-connection
view" to see a connection's rate limit.

```bash
bk repository-connection list [flags]
```

### Flags

| Flag | Description |
| --- | --- |
| `-o`, `--output=""` | Output format. One of: json, yaml, text |
| `--debug` | Log HTTP API traffic to stderr; bodies may contain sensitive data |
| `--json` | Output as JSON |
| `--org=STRING` | Organization slug for this invocation (overrides environment and configuration) |
| `--text` | Output as text |
| `--yaml` | Output as YAML |

### Examples

List repository connections:

```bash
bk repository-connection list
```

List repository connections in JSON format:

```bash
bk repository-connection list -o json
```

## View a repository connection

View a repository connection and its GitHub API rate limit.

View a repository connection's service account, host, and GitHub API rate limit.
Requires organization administrator access.

The rate limit is the cached GitHub installation core API quota for this
connection. It is not the Buildkite API rate limit. It is shown as unavailable
(`rate_limit`: null in JSON and YAML) when no cached quota exists or the
connection type has no GitHub quota. If the reset time has passed, the quota has
reset since it was cached, so the used and remaining values are stale.

```bash
bk repository-connection view <connection-id> [flags]
```

### Arguments

| Argument | Description |
| --- | --- |
| `<connection-id>` | Repository connection UUID, from bk repository-connection list |

### Flags

| Flag | Description |
| --- | --- |
| `-o`, `--output=""` | Output format. One of: json, yaml, text |
| `--debug` | Log HTTP API traffic to stderr; bodies may contain sensitive data |
| `--json` | Output as JSON |
| `--org=STRING` | Organization slug for this invocation (overrides environment and configuration) |
| `--text` | Output as text |
| `--yaml` | Output as YAML |

### Examples

View a repository connection:

```bash
bk repository-connection view 01234567-89ab-cdef-0123-456789abcdef
```

View a repository connection in JSON format:

```bash
bk repository-connection view 01234567-89ab-cdef-0123-456789abcdef -o json
```
